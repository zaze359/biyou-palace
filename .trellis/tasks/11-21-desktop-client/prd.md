# 碧游宫 V2 · 桌面客户端（dsh 壳/单机阵/观星台/开阵）

## Goal

交付 macOS / Windows 桌面客户端：默认单机自闭环，可主动开阵担任阵眼；提供本地模型、开阵/成员管理与品牌状态；取代旧“聊天客户端”定位。

## Scope

- 基于 dsh 的 Electron 壳，固定 dsh / Electron / Node 版本。
- 单机：直接使用 dsh 原生 Agent 完成目标；不自建 agent loop、任务外壳或本地任务板。
- 联阵：默认不广播；用户点「开阵」后选择开放阵/闭阵，成为阵主。
- 本地模型：由独立插件 `@biyou/dsh-local-models` 提供内置 llama.cpp 运行时与 GGUF 下载/托管，注册为 dsh provider；不再以 Ollama 作为主路径。
- 开阵弹窗、阵列表（寻阵）、成员列表、踢人、散阵。
- 品牌与状态：dsh 插件提供品牌位与运行状态；观星台/功德殿后置。

## Requirements

1. 干净安装后无需 Docker、NewAPI、阵图、灵脉即可完成本地任务闭环。
2. 启动默认单机，不监听/不广播联阵；开阵后才广播。
3. 本地配置、会话、任务、产物写入用户数据目录，不写仓库目录。
4. 模型密钥只留在主进程/系统密钥链，不回传渲染进程。
5. 开阵支持开放阵/闭阵；入阵无阵主确认；阵主可踢人。
6. 关闭/退出时清理子进程；重启后任务与历史不丢。
7. 前端可复用 dsh UI，但需品牌壳与碧游宫入口；禁用 dsh 集群级 Agent Teams 编排。

## Acceptance Criteria

- [ ] macOS 未签名 `.app` 可启动；干净环境完成一次本地任务闭环。
- [ ] Windows 构建脚本/CI 可产出未签名安装包。
- [ ] 启动默认不广播；点开阵后 Android 能在 5 秒内发现。
- [ ] 开放阵/闭阵入阵、心跳、踢人、散阵按联阵契约工作。
- [ ] 重启客户端后任务、产物、配置仍在。
- [ ] 退出后无残留 Python/Node/模型服务进程。

## Dependencies

- `11-21-lan-formation`
- `11-22-local-models-plugin`（本地模型插件）
- 后续（任务治理/联阵扩展）：`11-21-agent-contracts`、`11-21-taskboard-cost`

## Out of Scope

- 单机首版的任务外壳、本地任务板/因果簿、香火账本、观星台与功德殿面板（后置）。
- 功德殿后端。
- 移动端 App（见 `11-21-mobile-client`）。
- 云端账号、公网大厅、自动更新、签名/公证/V1.1。
