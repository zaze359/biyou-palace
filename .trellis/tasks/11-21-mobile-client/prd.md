# 碧游宫 V2 · 移动端（Android 先行/iOS 规划/入阵/轻任务）

## Goal

交付 Android 先行、iOS 同步规划的移动端：本地轻任务闭环，可寻阵/入阵作为外门仙徒接任务与回禀；iOS 共用协议与 KMP 核心，V2 不要求交付。

## Scope

- Android App：基于现有 `nodes/sanxian` 的 KMP + llama.cpp 基础产品化。
- 本地轻任务：对话、OCR、Embedding、文本分类、轻量文档问答。
- 联阵：寻阵、开放阵/闭阵入阵、心跳、离阵、接任务、回禀。
- iOS：共享 KMP 核心与联阵协议，平台 UI 与 llama.cpp 绑定架构预留。
- 后台存活、温度/电量降载、外门仙徒能力声明。

## Requirements

1. 启动默认单机，不自动寻阵；用户主动「寻阵」。
2. 同网段 5 秒内看到桌面阵列表；无 mDNS 时 UDP 兜底。
3. 开放阵直接入阵；闭阵校验阵符；均无阵主确认。
4. 入阵后作为 `root: outer`，上报神通/法宝/模型/并发；接轻任务并回禀。
5. 不承担完整多 Agent 编排与重工具链；复杂任务移交桌面端或排队。
6. 心跳 10s、租约 30s；被踢/阵散后回单机，本地数据不丢。
7. iOS 目标不进入 V2 交付，但协议与核心必须可复用。

## Acceptance Criteria

- [ ] Android 单机完成一次轻任务闭环。
- [ ] Android 发现桌面阵并在 5 秒内展示。
- [ ] 开放阵/闭阵入阵、心跳、离阵按联阵契约工作。
- [ ] 入阵后可接任务并回禀；被踢/阵散后回单机。
- [ ] 温度/电量异常时降载，不崩溃。
- [ ] iOS 复用架构与协议说明完成，不要求 V2 可运行。

## Dependencies

- `11-21-lan-formation`
- `11-21-agent-contracts`

## Out of Scope

- iOS V2 交付、完整阵眼、重工具、长时间后台任务。
