## 2. Industry form language
本项目的形式语言是「神话命名的硬核基础设施」：语义层是仙侠（碧游宫、青萍剑、阵图、仙徒），工程层是分布式系统。这决定了标志不能是纯写实仙侠插画（无法缩到 16px），也不能是纯技术几何（丢失身份线索）。取法是**保留一条文化身份线索 + 极简几何骨架**。

## 4. Color constraints
用户已选青绿体系，覆盖「桌面 UI 不引入第二套色板」的默认约定：品牌标志与界面 accent 分属两个系统，需在规范中声明。所有标志颜色从参考图提取，不引入 UI 蓝。

## 6. Design floor
最严苛场景 = 16px 应用图标。技术底线：图元 ≤ 3（含辅助）、主族线宽 ≥ 6（@100px 画布）、必须单色与反白可用、禁用渐变/阴影/肌理作为识别要素、安全区 = 最小元素宽度。
