# Visual Motif Derivation — 碧游宫（修订版）

来源：青萍剑海报（仅作内容参考，不保留原图）。方法论：DECONSTRUCT → SELECTIVE PRESERVATION → ABSTRACT → RECONSTRUCT。
修订说明：用户指正——(1) 参考图不进入成品；(2) 剑与青莲同为画面主体，青莲不得降级。本版据此重做评分与映射。

## Phase A — 空间事实提取

| # | 观察事实 | 可标志化评分 | 理由 |
|---|---|---|---|
| F1 | 单轴垂直长条剑身，长宽比约 7:1，剑尖收束为一点 | **High** | 一个渐收矩形/多边形即可，16px 成立 |
| F2 | 剑尖下方的青莲：中心莲蓬 + 左右对称展开的莲瓣，托住剑尖 | **High** | 用户指定主体；可压为一个对称弧瓣组 + 一条水平基线 |
| F3 | 剑格左右对称的横向短臂，位于剑身上三分之一处 | **Medium** | 与青莲争主体，降为修饰；16px 下可并入剑身顶端 |
| F4 | 剑身青绿、剑格深墨绿、莲花浅青，底为宣纸米白 | **High** | 三角色清晰，可提取为 primary/structural/accent/panel |
| F5 | S 形烟雾环绕剑身 | Low | 依赖笔触与渐变，违反 CLEAN 与单色纪律，删除 |
| F6 | 背景远山、宝塔、书法题字 | Low | 场景细节，非结构事实，删除 |

## Phase B — 语义到结构映射（剑 + 青莲双主体）

| 主体 | 观察到的事实 | 几何决策 | 判据 |
|---|---|---|---|
| 剑（主导） | F1 垂直闭合体，F3 深墨绿 | 主族 P2：渐收竖条，structural 深墨绿，尖端朝下插入莲心 | 16px 下竖条独立可辨 |
| 青莲（主体） | F2 对称弧瓣 + 水平基线，F4 浅青 | 辅助族：以「一条开口向上的弧 + 一条水平基线」暗示莲瓣托举，accent 浅青 | 与竖条接触形成「插入」关系；不可删 |
| 守护/内敛（语义） | 剑尖进入莲心 | 竖条尖端与弧瓣最低点相接，无外扩元素 | 负空间形成稳定三角 |

**主族**：P2 渐收竖条（剑）—— 识别核心。
**主体辅族**：开口弧 + 水平基线（青莲）—— 与剑并列，承载品牌名「青」与「莲」双语义，**不可删**。
**修饰**：剑格横臂（F3）—— 仅大尺寸版本保留，16px 版省略。
总图元 3–4，符合 ≤ 6 与 16px 底线（简化版 3 图元）。
